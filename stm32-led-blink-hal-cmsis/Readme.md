# STM32 LED Blinking using HAL & CMSIS

A basic STM32 embedded firmware project demonstrating LED control using
STM32 HAL and CMSIS on an STM32 Nucleo development board.

## 📌 Project Overview

This project implements periodic blinking of the onboard LED on an
STM32 Nucleo board.

The project was developed using Embedded C with STM32 HAL APIs and
CMSIS-based device definitions.

## 🛠️ Hardware Used

- STM32 Nucleo Board
- Onboard User LED
- USB connection for programming and debugging

## 💻 Software & Tools

- STM32CubeIDE
- Embedded C
- STM32 HAL
- CMSIS
- STM32CubeMX
- ST-LINK

## ⚙️ Working

1. STM32 GPIO peripheral is initialized.
2. The onboard LED GPIO is configured as an output.
3. The firmware toggles the LED state periodically.
4. The application runs continuously on the STM32 Nucleo board.

## 🔧 Key Concepts

- STM32 GPIO
- CMSIS
- STM32 HAL
- Embedded C
- GPIO Output Configuration
- Microcontroller Firmware
- Hardware Debugging
